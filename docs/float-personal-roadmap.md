# Float 个人版路线图

> 用途：集中记录个人分支的目标、优先级、已完成事项与关键决策。  
> 更新日期：2026-09-29  
> 工作目录：`E:\gpt-float`  
> 部署分支：`personal`

## 当前原则

1. 先保证数据安全和可回退，再增加功能。
2. 尽量做小步、可验证的改动，避免一次影响多个内置 App。
3. 优先降低每轮模型调用成本，再扩展高频后台功能。
4. API Key 默认留在用户设备；确需进入服务端时必须明确提示风险。
5. 保留上游同步能力：个人改动留在 `personal` 分支，更新上游后逐项解决冲突。
6. 每次部署都先构建和健康检查；失败时保留或自动回滚到旧版。

## 暂缓或已知限制

- NovelAI V5 当前不可用，V4/V4.5 可用；先不围绕 V5 做大改。
- NovelAI 参考图能力与当前接口支持情况需要单独验证。
- 中国大陆网络访问 NovelAI 通常仍需要代理；浏览器直连与服务端转发受网络位置影响。
- Supabase 免费额度不一定是实际瓶颈，但付费与跨境支付不方便，因此暂不作为 Float 主存储。
- PWA 本地数据不能当作唯一长期备份，仍需保留导出文件。
